# Kingsley Watches

A premium, responsive static e-commerce website for Kingsley Watches.

## Included
- Home page
- Collection/shop page
- Product detail pages
- Local-storage shopping cart
- Cash-on-delivery checkout UI
- About and contact pages
- Shipping, returns and privacy placeholders
- Responsive mobile design
- SEO-ready metadata
- No API keys or secrets required

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy
This project can be deployed directly to Vercel, Netlify, GitHub Pages, or any static hosting service.

## Before launch
Replace placeholder product data/images, business email, WhatsApp number, shipping/return/privacy policies, and connect the checkout form to your real order-processing method.

## Important
The checkout is intentionally a front-end demo flow. It does not process payments or store orders on a server.
